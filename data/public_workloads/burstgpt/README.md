# BurstGPT workload

The paper uses the `BurstGPT_without_fails_3.csv` release from the upstream BurstGPT repository.

- Repository: https://github.com/HPMLL/BurstGPT
- Release file: `BurstGPT_without_fails_3.csv`
- Paper: https://arxiv.org/abs/2401.17644
- License: CC-BY-4.0 according to the upstream release

The repository's `scripts/data/prepare_burstgpt_workload.py` downloads the source file when requested and creates the derived bucketed trace locally. The raw file and derived trace are not committed to this source release.
